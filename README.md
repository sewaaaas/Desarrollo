# CIDRIX

CIDRIX es un proyecto colaborativo de mesa de ayuda para registrar, organizar y dar seguimiento a solicitudes de soporte técnico.

La idea es reunir en una sola plataforma los tickets, usuarios, comentarios y reportes, con separación de información por organización.

## Tecnologías

- **Backend:** NestJS, TypeScript, Prisma y PostgreSQL.
- **Frontend:** React, Vite y Tailwind CSS.
- **Entorno de desarrollo:** Docker y Git.

## Contenido del repositorio

- [cidrix-api](cidrix-api/): API, base de datos y reglas del sistema.
- [cidrix-web](cidrix-web/): interfaz web.
- [docs](docs/): notas de implementación y pruebas.

## Estado

El proyecto sigue en desarrollo. Ya se han trabajado módulos de autenticación, usuarios, tickets, comentarios, adjuntos, métricas y notificaciones. Algunas funciones todavía están en revisión y pruebas.

Para ejecutarlo en local, revisa las instrucciones de cada carpeta.
